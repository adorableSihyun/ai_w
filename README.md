# 고려대학교 「○○○」 강의 소개 사이트

서버 없이 브라우저에서 바로 열리는 강의 소개 웹사이트입니다.
벚꽃 분위기의 분홍·보라 테마에, 주차별 커리큘럼·수업 달력·투표·수강 신청·출석·과제 제출·관리자 화면을 갖추고 있습니다.

- 사이트의 **모든 내용은 `config.js` 한 파일**에 모여 있습니다.
- 관리자 화면(오른쪽 위 🔒)에서 내용을 고치고, 설정 파일로 내려받아 교체하는 방식으로도 관리할 수 있습니다.

---

## 1. 파일 구성

| 파일 | 역할 | 고칠 일 |
|---|---|---|
| `index.html` | 페이지 뼈대 | 거의 없음 |
| `config.js` | **사이트 내용 전체** (학과·과목명, 일정, 커리큘럼, 공지, FAQ, 교수자, 비밀번호 해시 등) | ✅ 여기만 고치면 됩니다 |
| `style.css` | 디자인 (색상·카드·반응형) | 색을 바꿀 때만 |
| `main.js` | 화면 구성, 일정·달력·마감 계산 | 없음 |
| `features.js` | 투표, 학생 공간(로그인·출석·과제), 수강 신청서, 팝업, 폭죽 | 없음 |
| `admin.js` | 관리자 화면 | 없음 |

## 2. 바로 열어 보기

`index.html`을 더블클릭하면 브라우저에서 열립니다. 설치할 것은 없습니다.
(Chrome, Edge, Safari, Firefox 최신 버전 권장)

## 3. 내용 고치기

### 방법 A. 관리자 화면에서 고치기 (추천)

1. 화면 오른쪽 위 **🔒 자물쇠**를 누르고 관리자 비밀번호를 입력합니다.
   - 기본 비밀번호는 사이트를 만든 사람에게 따로 전달되었습니다. **배포 전에 꼭 [비밀번호 변경]에서 바꾸세요.**
2. **사이트 편집**에서 영역(기본 정보, 첫 화면, 커리큘럼, FAQ …)을 골라 내용을 고칩니다.
   - 목록 항목은 `+ 추가`, `↑ ↓`(순서), `✕`(삭제)로 관리합니다.
   - 어떤 주차에 과제를 새로 넣는 것처럼 구조를 바꿀 때는 **고급(JSON)** 탭을 씁니다.
3. **저장하고 적용**을 누르면 지금 쓰는 브라우저에 바로 반영됩니다.
4. **모든 방문자에게 반영하려면** → **설정 파일 › config.js 내려받기** → 받은 파일로 사이트 폴더의 `config.js`를 교체 → 다시 배포(5장 참고).

> 관리자 화면에서 고친 내용은 먼저 **그 브라우저에만** 저장됩니다(“브라우저 수정본”).
> 다른 컴퓨터나 배포된 사이트에는 config.js를 교체해야 반영됩니다.
> 수정본을 지우고 원본으로 돌아가려면 **설정 파일 › 고친 설정 지우기**를 누르세요.

### 방법 B. `config.js`를 직접 고치기

메모장이나 VS Code로 `config.js`를 열어 따옴표 안의 글자를 고치고 저장한 뒤 새로고침합니다.
파일 안에 항목별 설명이 주석으로 달려 있습니다.

- 학과·과목명: `site.department`, `site.courseName`
- 수업 날짜: `schedule.startDate`(1주차 날짜)와 `schedule.holidays`(휴강일)만 정하면 15주 날짜·달력·과제 마감이 자동 계산됩니다.
- 과제: 각 주차의 `assignment` (마감은 기본으로 수업 6일 뒤 23:59)
- 교수자 사진: `images` 폴더에 사진을 넣고 `instructor.photo: "images/professor.jpg"`

> ⚠️ 관리자 화면에서 내려받은 config.js는 주석이 빠진 형태입니다. 내용은 동일하게 동작합니다.

## 4. 관리자 화면 메뉴

| 메뉴 | 할 수 있는 일 |
|---|---|
| 대시보드 | 신청 수, 등록 수강생, 오늘 출석, 과제 제출, 공지 수, 투표 순위 |
| 공지 관리 | 공지 올리기·수정·삭제·고정. 사이트 맨 위 “공지사항”에 바로 표시 |
| 수강생 명단 | 한 명씩 추가, 여러 명 붙여 넣기(`학번,이름,학과,이메일`), CSV 파일 불러오기, 신청자 전원 추가, CSV 내려받기 |
| 수강 신청 내역 | 신청서 목록·검색·삭제, 엑셀(CSV) 내려받기 |
| 출석 현황 | 학생 × 주차 출석표(출/지/결), 출석률, CSV 내려받기 |
| 과제 제출 현황 | 과제별 제출 인원, 제출 목록(지각 표시), CSV 내려받기 |
| 사이트 편집 | 모든 영역의 내용 수정, 고급(JSON) 편집 |
| 설정 파일 | config.js 내려받기 / 불러오기 / 원래대로 되돌리기 |
| 비밀번호 변경 | 새 비밀번호를 해시로 저장 (바꾼 뒤 config.js를 내려받아 교체해야 배포본에 적용) |

- CSV 파일은 한글이 깨지지 않도록 만들어져 있어 **엑셀에서 더블클릭으로 바로 열립니다.**
- 수강생 명단을 1명 이상 등록하면 **명단에 있는 학생만** 학생 공간에 로그인할 수 있습니다.

## 5. 배포하기 (인터넷 주소로 공개)

### 방법 1. GitHub Pages (무료, 추천)

이 저장소(`adorableSihyun/ai_w`)에서:

1. GitHub 저장소 페이지 → **Settings** → 왼쪽 **Pages**
2. **Build and deployment › Source**: `Deploy from a branch`
3. **Branch**: `main` / 폴더 `/ (root)` → **Save**
4. 1~2분 뒤 `https://adorablesihyun.github.io/ai_w/` 에서 열립니다.

내용을 바꿀 때는 `config.js`를 교체해 커밋·푸시하면 자동으로 다시 배포됩니다.

```bash
git add config.js
git commit -m "강의 내용 수정"
git push
```

> 저장소가 공개(Public)이면 config.js 내용도 누구나 볼 수 있습니다. 개인정보(학생 명단 등)는 config.js에 넣지 마세요.

### 방법 2. Netlify Drop (가입 후 끌어다 놓기)

1. https://app.netlify.com/drop 접속(로그인)
2. 사이트 폴더 전체를 브라우저 창에 끌어다 놓기 → 주소가 바로 생성됩니다.
3. 수정할 때는 같은 사이트의 **Deploys** 화면에 폴더를 다시 끌어다 놓습니다.

### 방법 3. 학교·학과 웹 서버

폴더 안의 파일(`index.html`, `config.js`, `style.css`, `main.js`, `features.js`, `admin.js`, 사진 폴더)을 그대로 서버의 웹 폴더에 올리면 됩니다. 별도 프로그램은 필요 없습니다.

## 6. 꼭 알아 둘 점 (데모 모드 · 보안)

### 데이터는 각자의 브라우저에만 저장됩니다 (데모 모드)
투표, 수강 신청서, 학생 로그인·출석·과제 제출, 수강생 명단은 **그 기기의 브라우저(localStorage)** 에만 저장됩니다.

- 학생이 자기 휴대폰에서 낸 신청서는 **교수자의 관리자 화면에 보이지 않습니다.**
- 과제 “제출”은 파일 이름·크기·시각만 기록하며 파일 자체는 올라가지 않습니다.
- 브라우저의 사이트 데이터를 지우면 기록도 사라집니다.

실제 수업에서 여러 학생의 데이터를 모으려면 서버 저장소가 필요합니다.
`features.js` 맨 위의 `store`(read / write / on / keys) 부분만 Firebase 같은 서비스로 바꾸면 나머지 기능은 그대로 동작하도록 만들어 두었습니다.
그 전까지는 수강 신청·과제 제출을 학교 LMS나 Google Forms로 받는 것을 권장합니다
(`schedule.submitUrl`에 LMS 주소를 넣으면 과제 제출 버튼이 그곳으로 연결됩니다).

### 관리자 비밀번호
- 비밀번호는 원문 대신 **솔트를 붙여 2만 번 반복한 SHA-256 해시**로만 저장됩니다. 코드에서 비밀번호를 그대로 읽을 수는 없습니다.
- 다만 서버가 없는 사이트라서, 이 잠금은 “관리자 화면을 일반 방문자에게 숨기는” 수준의 장치입니다. 개발자 도구를 다룰 줄 아는 사람은 우회할 수 있고, 짧거나 흔한 비밀번호는 해시에서 추측될 수 있습니다.
- **12자 이상의 추측하기 어려운 비밀번호**를 쓰세요. 민감한 정보 보호가 필요하면 서버 인증을 도입해야 합니다.

## 8. 문제 해결

- **화면이 하얗게 나와요** → `config.js`에 쉼표·따옴표가 빠졌을 가능성이 큽니다. 브라우저 개발자 도구(F12) › Console에서 오류 줄을 확인하세요.
- **config.js를 고쳤는데 그대로예요** → 관리자 화면의 “브라우저 수정본”이 우선 적용되고 있습니다. **설정 파일 › 고친 설정 지우기**를 누르세요.
- **관리자 비밀번호를 잊었어요** → 비밀번호를 바꾼 뒤 config.js를 교체하지 않았다면 **고친 설정 지우기** 후 원래 비밀번호로 들어갈 수 있습니다. config.js까지 교체했다면, 개발자 도구 Console에서 `SiteAdmin.hashPassword("새비밀번호", "<config의 salt>", 20000)`으로 해시를 만들어 `config.js`의 `admin.passwordHash`에 넣으세요.
